# OpenBOR Frontend Launcher V2.0

Validated build: `20261002-1456`.
Requirements: Apple Silicon Mac running macOS 14 or later.

## Current Launcher

- Native arcade-style launcher with optional animated background.
- Metal and OpenGL host rendering using the current V2 engine.
- English, Italian, Spanish and Portuguese for launcher and in-game menus.
- Configurable quick-menu and rewind shortcuts; keyboard and controller input.
- Live session suspend/resume and disk savestate slots.
- Shader selection, with per-game or global defaults.
- Rewind timeline with 30 half-second checkpoints, chronological previews,
  non-destructive browsing, confirmation/cancel and short navigation sounds.
- Music decoder and buffered audio restored to the selected rewind checkpoint.
- Game preview fully visible above the timeline; compact windowed controls.

## Compatibility And Validation

The user validated gameplay and the latest rewind layout on the installed
launcher. Automated Hyper Duel integration tests passed with both Metal and
OpenGL, including browsing, cancellation, state restoration, movement, attack,
music restoration, scrolling and session suspend/resume.

Rewind history is session-local and resets at level changes. Exact audio
checkpoints are currently part of rewind, not disk savestates. New disk captures
use V8; V6/V7 imports remain supported, but cannot recover fields that those
older formats did not record. Compatibility with every OpenBOR game is not
guaranteed.

The bundle is locally signed, not an Apple-notarized distribution. macOS may
require explicit approval to open it. No games or personal runtime data are
included; import your own compatible PAK files.

## Historical Builds

The separate historical archive preserves the locally available launcher ZIP
builds for reference, not as recommended versions. Intermediate builds can
contain known regressions. The legacy unversioned package is cleaned to remove
bundled game PAKs and runtime data; its original local file is not modified.

The packaged source commit corresponds to the current launcher only. Exact
historical source revisions are not reconstructed from binary packages.
