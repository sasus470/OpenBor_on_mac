# OpenBOR Frontend Launcher V2.0 (20261003-1512)

Update from the previously published build **20261002-1902**.
Requires an Apple Silicon Mac running macOS 14 or later.

## Library And Covers

- Choose the original sidebar list or a centered cover grid in Settings. The layout is remembered between launches.
- Select a custom PAK library folder, open it in Finder or restore the default folder. Existing game files are not moved or copied.
- Click a game cover or title to select it; double-click to launch. Hovering over titles adds a subtle animation that respects Reduce Motion.
- Library layout labels now update immediately when switching between English, Italian, Spanish and Portuguese.
- Search for covers in an embedded browser, automatically using the selected game's title. Preview a result and explicitly confirm before importing it.
- Online cover downloads are validated and size-limited. If the original image cannot be downloaded, a search thumbnail can be used with a lower-resolution notice.
- Local cover-file import remains available. Automatically refreshed covers no longer overwrite manually imported covers.

## Game Launch And CLI

- New persistent **Start games in fullscreen** option in Settings, available with both Metal and OpenGL host rendering.
- Closing a game launched with `--pak`, `--launch` or the direct PAK shortcut now also quits the launcher and shuts down its engine. Normal library launches keep the launcher available for resume or another game.
- Raw CLI engine launches also close the launcher when that separate engine application exits.
- Removed unnecessary shutdown delays for hosted engines. Suspended engines are awakened before termination so normal save and cleanup code can run instead of waiting for a forced-termination timeout.
- Three real-game CLI close tests measured **0.18-0.28 seconds** from window close to launcher exit; actual timings depend on the machine and session.
- CLI help documents the automatic-exit behavior. The previous `--help`, `-h` and `--logs-dir` fixes are retained.

## Validation

The user validated the library layouts, folder selection, cover search/import,
language changes and automatic CLI exit. Automated tests cover library selection
and preferences, four-language layouts, image validation and cover import,
native fullscreen entry with Metal/OpenGL, CLI versus normal window-close
behavior, real embedded-game shutdown latency, help, game launch and custom log
directories. No test engine remained active after shutdown.

Existing V2 quick-menu, savestate, shader, rewind, keyboard and controller
features are retained. Compatibility with every OpenBOR game is not guaranteed.
Rewind history is session-local; exact audio checkpoints belong to rewind, not
disk savestates. V8 captures and V6/V7 imports remain supported.

## Download And Safety

Download `OpenBOR-Frontend-Launcher-V2.0-20261003-1512-macOS-arm64.zip`.
Extract the app and place it in Applications, replacing an older launcher if
desired. `SHA256SUMS.txt` and `release-manifest.json` identify the package.

The app is locally signed, not Apple-notarized; macOS may require explicit
approval to open it. **No games, ROMs, user saves or personal runtime logs are
included.** Supply your own compatible PAK files and import only cover images
you have permission to use.

Previous releases and the separate historical development archive remain
available. Historical intermediate builds are not recommended for normal use.
